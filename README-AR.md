# AI TEAM WORKER

واجهة عربية أولية لتنسيق ثلاثة أدوار: مدير/مخطط، منفذ، ومراجع. لكل دور مزود وموديل ومفتاح مستقل.

## التشغيل على Android
ارفع الملفات إلى المستودع، ثم فعّل GitHub Pages من Settings ثم Pages. افتح رابط الموقع في Chrome واختر إضافة إلى الشاشة الرئيسية.

## المزودون
- Google Gemini عبر Generative Language API.
- واجهات متوافقة مع OpenAI عبر مسار /v1/chat/completions. أدخل عنوان API الأساسي عند الحاجة.
- يلزم مفتاح صالح وموديل متاح لكل دور. الأسعار والحصص تختلف حسب المزود.

## قيود وأمان
- مفاتيح API لا تحفظ في Local Storage، لكنها تبقى في حقول الصفحة حتى إغلاقها أو تحديثها.
- الاتصال مباشر من المتصفح؛ قد تمنع بعض الخدمات CORS أو تقيّد مفاتيح المتصفح. للاستخدام العام الآمن نحتاج خادماً وسيطاً يحمي الأسرار.
- الأدوار تعمل بالتتابع وليست وكلاء في الخلفية.
- لا يوجد تنفيذ أوامر على الهاتف، أو تعديل تلقائي للمستودع، أو بناء APK أصلي في هذه النسخة.
- لا تضع مفاتيح API في ملفات GitHub.
